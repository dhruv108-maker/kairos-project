## Introduction 📊

Shadcn Dashboard is a production-ready dashboard starter with dashboard layouts, authentication pages, forms, tables, profile screens, and reusable UI components.

Available in both **React (Vite)** and **Next.js** versions!

- [View Demo (React)](https://shadcndashboard-demo.vercel.app)

## Key Features ✨

- **Modern Dashboard** - Ready-to-use dashboard layout with statistics, charts, and widgets
- **Apps** - Blog, Notes, and Tickets apps out of the box
- **Authentication Pages** - Login, Register, Forgot Password, OTP Verification, Reset Password, Two-Factor Auth
- **Forms & Tables** - Vertical & Horizontal form layouts and a data table
- **User Profile** - Profile page with connections and activity views
- **Built with React 19 + Vite** - Modern, fast, and SEO-friendly
- **Tailwind CSS v4** - Utility-based styling and theming
- **Responsive & Mobile-First** - Designed for all devices
- **Dark Mode Support** - Theme toggle support
- **Rich Charting** - Recharts integration
- **Rich Text Editor** - TipTap-powered editor for the Blog app


## 🚀 Quick Start

### Prerequisites

- Node.js 18, 20, or 22+
- npm

1. **Install dependencies:**

   ```bash
   npm install
   ```

2. **Start the development server:**

   ```bash
   npm run dev
   ```

   The site will be available at `http://localhost:5173`.

3. **Build for production:**

   ```bash
   npm run build
   ```

4. **Preview the production build:**

   ```bash
   npm run preview
   ```

## 🧞 Available Commands

| Command | Action |
| :-- | :-- |
| `dev` | Starts the Vite development server with hot reload |
| `build` | Creates an optimized production build via TypeScript + Vite |
| `preview` | Previews the production build locally |
| `lint` | Runs ESLint |
